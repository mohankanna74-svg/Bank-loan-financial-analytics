# Bank Loan Financial Analytics

## 📌 Project Overview

The **Bank Loan Financial Analytics** project analyzes loan portfolio data to understand loan applications, funded amounts, repayments, borrower characteristics, and overall loan performance.

The project combines **SQL, Excel, Tableau, and AI-assisted analysis** to transform raw banking data into meaningful financial KPIs, interactive visualizations, and business insights.

---

## 🎯 Business Objectives

* Analyze overall loan application activity
* Track funded and received loan amounts
* Monitor loan portfolio performance
* Identify trends in loan applications and funding
* Compare Good Loans vs Bad Loans
* Analyze borrower and loan characteristics
* Create an interactive financial analytics dashboard
* Generate data-driven business insights

---

## 📊 Key Performance Indicators (KPIs)

The project analyzes the following major KPIs:

* Total Loan Applications
* Total Funded Amount
* Total Amount Received
* Average Interest Rate
* Average Debt-to-Income Ratio (DTI)
* Month-to-Date (MTD) Loan Applications
* Month-to-Date (MTD) Funded Amount
* Month-to-Date (MTD) Amount Received
* Good Loan Applications
* Good Loan Funded Amount
* Good Loan Amount Received
* Bad Loan Applications
* Bad Loan Funded Amount
* Bad Loan Amount Received
* Good Loan Percentage
* Bad Loan Percentage

---

## 🔍 Analysis Performed

### 1. Loan Application Analysis

Analyzed loan applications based on:

* Monthly trends
* Loan purpose
* Loan term
* Loan grade
* Home ownership
* Employment length

### 2. Loan Funding Analysis

Analyzed:

* Total funded amount
* Monthly funding trends
* Funding by loan purpose
* Funding by loan grade
* Funding by home ownership
* Funding by loan term

### 3. Loan Repayment Analysis

Analyzed:

* Total amount received
* Monthly repayment trends
* Amount received by loan status
* Amount received by loan purpose

### 4. Good Loan vs Bad Loan Analysis

Loans were grouped into two categories.

**Good Loans**

* Fully Paid
* Current

**Bad Loans**

* Charged Off

The analysis compares:

* Number of applications
* Funded amount
* Amount received
* Percentage contribution

### 5. Borrower Analysis

Analyzed borrower characteristics including:

* Annual income
* Employment length
* Home ownership
* Loan purpose
* Loan grade
* Loan term
* Debt-to-income ratio
